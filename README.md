# brenoalcaraz.github.io

Personal portfolio of Breno França Alcaraz Ferreira, live at **https://brenoalcaraz.github.io**.

It's a static page: plain HTML and CSS, no build step. English is the default. The flag button switches to Portuguese and remembers the choice. You can also link straight to a language with `?lang=pt` or `?lang=en`.

```
index.html         page content (EN and PT side by side, toggled by data-l)
assets/style.css   styles, light and dark mode
assets/*.pdf       résumés for download
```
